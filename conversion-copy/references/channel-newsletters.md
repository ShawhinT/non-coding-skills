# Channel: Newsletters (meant to sell)

**Voice, templates, subject-line patterns, signoff ("Keep building, / Shaw"), and P.S. patterns are owned by `newsletter-writer` — draft there.** This file is the conversion-diagnosis layer for sell sends: apply it after (or while) the draft exists.

## Sell-send checks

1. **Advice ratio.** ~70% of the word count is value the reader keeps from reading alone; the offer is the tail. Structure: hook → insight or story → natural segue ("this is why I built...") → the offer → single low-friction CTA → P.S. (restate CTA, or add proof/scarcity). Advice-shaped sells get forwarded; ad-shaped sells get deleted (AndCo's advice email: 65% CTR, 55% reply rate).
2. **One offer per email.** No "oh, and also" — it kills conversion on both.
3. **Subject + first line carry the send.** The first 60–100 characters are preview text — no greeting, no wasted setup. For an established list, pattern consistency beats cleverness (Growth Design's "New: 🍿 Case Study #052" holds 60%+ opens on reputation alone).
4. **Filter-score the load-bearing lines:** subject, first line, segue, CTA, P.S. — ✓/✗ each against visualize / falsify / unsignable.
