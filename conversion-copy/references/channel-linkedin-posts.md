# Channel: LinkedIn Posts (meant to sell)

**Voice, hooks, structure, and mechanics are owned by `linkedin-voice` — load it for every LinkedIn draft.** This file adds only the conversion layer for posts selling something (a workshop, cohort, intensive, or offer-tied signup). General posts: `linkedin-voice` (drafting) / `sfc-helper` (ideation).

## Sell-post checks

1. **One idea, one CTA.** Pick the sharpest angle and commit — the next post is next week. Multiple angles dilute both.
2. **Give the value in the post; don't redirect.** Delivering the insight on-platform proves the offer's quality — the CTA is for *more*, not for the insight itself. (The Kyiv Independent beat the Kyiv Post 5-to-1 by being useful in the feed instead of linking out.)
3. **Low-friction close, matched to funnel stage.** Comment-prompt ("comment 'operator' and I'll DM the one-pager" — also boosts reach) > DM-prompt > link in comments. Never "book a call" on first exposure.
4. **Scarcity is real and specific or absent.** "5 spots, gone by Sunday" — never "limited time."

## Three shapes

- **Story:** hook (scene/confession) → 2–4 short paragraphs → lesson → offer tied to it → CTA.
- **Contrarian take:** claim → why most get it wrong → what works, shown concretely → offer → CTA.
- **Proof drop:** client result → quick context → what changed → how → offer + CTA.
