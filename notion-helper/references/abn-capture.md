# Capturing an email blast into an ABN page

Read this when appending a newsletter or email blast to its dated ABN page. The *content* is
`newsletter-writer`'s domain; this file covers only the Notion-write layout so the page matches
Shaw's convention.

**Capture what shipped, not what was drafted.** Pull the final copy from the channel's own record
— the Kit broadcast for newsletters, the host's inbox copy in Gmail for Luma and event sends — and
link that record at the bottom of the page. Don't invent fields the channel doesn't have: Luma has
no preview text, so the Subject + Preview block collapses to Subject alone.

## Standalone edition

The page *is* the container, so don't wrap the draft in your own headings or labels:

- The source the newsletter repurposes stays at the top, followed by a `---` divider. Label it for
  what it is (`Source blog: <title>`, a LinkedIn post, a video) so the origin is clear at a glance.
- **Subject + Preview** go together as one tight block: `**Subject**: ...` then
  `<br>**Preview:** ...`. Subject lines are written plain — never wrapped in quotes. When the
  send A/B tests subjects, list every variant (`**Subject A**: ...`, `**Subject B**: ...`).
- The body follows as written. The CTA isn't always a P.S. — sometimes it's an inline line right
  before the signoff, so capture whatever the final draft used.
- Keep the signoff compact: `Keep building,<br>Shaw`.
- A trailing asset (e.g. a cheat-sheet image) stays *after* the signoff, mirroring the email.
- No section heading above the draft.

## Campaign page

When the ABN row is one promo among several across channels (its `Campaign` property is set), the
page carries a heading above the copy:

    Subject ideas:
    - <candidate>
    - <candidate>

    ## Copy

    **Subject**: <as sent>
    **Preview:** <as sent>

    <body as sent>

The subject-ideas list is a shared library, not scratch work — later sends in the campaign pick
from it rather than inventing new lines. Keep it on the page and note which one shipped.

Draft in the form it will ship. Shaw copies the page into the sending tool, so the body should
already read the way the recipient will see it — no wrapper that strips formatting he'd redo.

This is the ABN-specific instance of the general "match formatting from recent examples" rule —
when in doubt, sample the last 1-2 ABN pages in the same campaign and mirror them.
